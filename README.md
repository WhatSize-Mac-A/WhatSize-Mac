## What Is WhatSize for Mac

whatsize mac is a disk space analyzer for macOS. It measures the byte size of a folder and everything inside
it, sorts the results biggest-first, and lets you move unwanted files to the Trash. Most of the time it just
works, quietly turning a mysterious full disk into a ranked, actionable list.

When it does not behave as expected, the cause is almost always a permission, a scope or a display setting
rather than a bug. This page collects the snags people hit with disk space analyzer mac scanning and the quick
fixes that clear them.

## When a Scan Feels Stuck

A scan that seems frozen is usually just working through a huge tree. whatsize mac walks every subfolder and
file, so a full-drive measurement of a packed disk genuinely takes time. Rather than waiting on the whole
thing, browse the folder while it measures — item sizes appear as they are counted, so you can start acting on
the biggest offenders before the scan finishes.

If it truly stalls, it is often a network share or an inaccessible system folder. Scanning a local folder
first, then adding others, keeps disk space analyzer mac scanning responsive and easy to reason about.

## Getting Accurate Numbers

- **Grant Full Disk Access** so whatsize for mac can read every folder and report honest totals.
- **Mind hidden and cache files** — they count toward the size, which is why totals can surprise you.
- **Compare like with like** — measure the folders you can clean rather than expecting an exact match to macOS
  storage figures that include purgeable space.
- **Rescan after deleting** — once you empty the Trash, run whatsize download mac again to confirm the space came back.

Kept in mind, these habits make the reported sizes trustworthy and the cleanup predictable.

## Frequently Asked Questions

**Why is my scan so slow?**
A full-drive scan measures every file, so it takes time. Point whatsize mac at a single folder for a quicker
result, and scan network volumes on their own.

**Why are some folders skipped or showing zero?**
macOS protects certain locations. Grant Full Disk Access so disk space analyzer mac scanning can read them and
report their real size.

**Why do the totals not match About This Mac?**
macOS counts purgeable space and local snapshots differently. whatsize for mac measures actual files, so focus
on the folders you can clean up.

**I deleted files but nothing freed up. Why?**
Moving items to the Trash with whatsize mac download does not reclaim space until you empty the Trash. Empty it,
then rescan.

**How do I avoid scrolling through thousands of rows?**
Use the filters. download whatsize for mac lets you narrow the view by size or type so you can find large files
mac quickly.

**Does it run on recent macOS and Apple Silicon?**
Yes. whatsize mac is a native macOS app that runs on both Apple Silicon and Intel Macs.
